# Анализ статистики правонарушений по регионам России

## Цель
Провести анализ статистики правонарушений по регионам России для выявления тенденций и особенностей, влияющих на уровень преступности.

## Задачи
1. Сформировать информационную базу исследования.
2. Разделить регионы на группы путем создания интервального ряда.
3. Выделить регионы-«фавориты» РФ (с аномально высоким уровнем правонарушений) и «отстающие» регионы.
4. Объяснить разницу между регионами по уровню преступности.
5. Оценить средний уровень преступности в России (расчет средних величин).
6. Охарактеризовать разброс данных через показатели вариации и проверить близость распределения к нормальному.
7. Определить форму распределения данных с визуализацией на графиках.
8. Исследовать временную динамику уровня преступности.
9. Сформулировать выводы и интерпретировать наблюдаемые тенденции.

## Актуальность
Анализ статистики правонарушений по регионам России имеет высокую актуальность в условиях современных социально-экономических изменений. Углубленное изучение данных позволяет:
- Выявлять региональные тенденции преступности.
- Оптимизировать меры профилактики и борьбы с правонарушениями.
- Адаптировать стратегии правоохранительных органов с учетом локальных особенностей.

Результаты исследования способствуют повышению общественной безопасности и укреплению доверия граждан к государственным институтам.
